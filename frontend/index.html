Where We Are

Built in the Open, Honestly

GokuShield is a new platform. Here's what that actually means for you.

What the scan does today

Checks your API against the OWASP API Security Top 10 and common misconfigurations (auth, rate limiting, headers, exposed data), then uses an AI model to summarize findings in plain language. You get a report — not an autonomous defense system, yet.

What "AI-powered" means here

Scan analysis is generated by an LLM reasoning over your scan results against known security frameworks. It does not yet retain memory between scans or adapt on its own — we're building a feedback loop where you can mark findings as accurate or not, which will genuinely improve future scans over time.

What we don't claim

We are not yet ISO 27001 or SOC 2 certified, and we don't have a large existing customer base to cite. We'd rather tell you that plainly than make up numbers. If formal certification happens, it'll be announced here with real evidence.

Security

Our Security Commitment

We're an early-stage platform, and we'd rather describe our security posture accurately than make claims we can't back up. This page will grow as our infrastructure and practices mature — and we'll update it with real evidence, not aspirational language.

What GokuShield Does Today

Scanning

GokuShield's scanner checks your API against:

  • The OWASP API Security Top 10
  • Common authentication and authorization misconfigurations
  • Missing or weak security headers
  • Rate limiting and exposure issues

Data Handling

Practices currently in place:

  • Passwords are hashed, never stored in plaintext
  • Access controls separate client and admin roles
  • We do not currently hold formal third-party security certifications

AI-Assisted Analysis

What it actually does

GokuShield's AI analysis, honestly described:

  • Summarizes scan findings from each individual scan in plain language
  • Prioritizes findings against known frameworks like OWASP
  • Does not currently retain memory between scans or predict unknown (zero-day) attacks — no security product can honestly claim that
  • Improves over time as we build out a feedback loop where you can confirm or correct findings

Automated Response

Roadmap — not yet built:

  • Automated remediation for a pre-approved, narrow set of low-risk fixes
  • Real-time security alerts on new scan findings
  • Comprehensive audit logs (already in place today)

Compliance and Certifications

We do not currently hold ISO 27001, SOC 2, or other formal third-party security certifications. If we pursue and obtain them, we'll post the real certificates here.

Incident Response

We're a small, early-stage team. If you have a security concern, contact us and we'll respond as quickly as we're able — we won't claim a 24/7 SOC we don't have.

Security Best Practices

We recommend our customers:

  • Use strong, unique passwords for all accounts
  • Enable multi-factor authentication where available
  • Regularly review access logs and security alerts
  • Keep software and systems updated
  • Follow the principle of least privilege for access control

Contact Our Security Team

If you have security concerns or need to report a security incident, please contact our security team immediately at security@gokushield.com.
